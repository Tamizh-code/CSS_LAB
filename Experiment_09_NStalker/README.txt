Experiment 09: Exploring N-Stalker - A Vulnerability Assessment Tool

For full step-by-step execution instructions and procedure, please refer to README.md in this directory.

Summary:
1. Launch N-Stalker Free Edition.
2. Update signature database via License Manager tab.
3. Enter Target URL under Scan Session tab.
4. Select Scan Policy (Full XSS, OWASP Policy, or Infrastructure Analysis).
5. Click Optimize Settings and Start Scan Session.
6. Generate HTML Report and analyze vulnerabilities.
